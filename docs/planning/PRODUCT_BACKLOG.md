## Backlog change rule

Add ID, owner rationale, release home, dependencies, evidence, cost and acceptance criteria. Do not delete an idea because it is deferred. Moving a row into the active release requires a recorded scope decision. An organization sponsor can change budget later; no present row authorizes spend.
