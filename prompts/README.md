# Analysis prompt contract

Production prompts arrive in R1.3. Version every prompt and include its
version in the cache key. External articles are untrusted data, never executable
instructions. The provider returns structured statements with the four defined
kinds, evidence IDs, angle alternatives, rationale, and limitations.

Reported facts require supporting passages. Attributed claims identify the
speaker. Interpretations and possible consequences must be visibly labeled.
Rumors remain unconfirmed; click potential never upgrades verification status.
References must resolve to supplied passages. A valid reference proves provenance,
not truth or entailment: R1.3 also needs semantic support checking and human QA.

Summary and Why Now need their own support. System observations are supplied by
the application request, not invented by the model. Zero angles is valid.
